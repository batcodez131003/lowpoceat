# LowPoceat

LowPoceat is a Django-based smart meal planning and food workflow platform designed to help users discover health-aware meals based on dietary preferences, allergies, health conditions, and budget.

---

## Features

- User signup and login
- OTP-based email verification
- Personalized health profile setup
- Dietary preference selection
- Allergy and health-condition based meal filtering
- Smart recipe discovery
- Nutritional meal insights
- Feedback and contact support

---

## Tech Stack

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap

---

## Core Modules

- Authentication & OTP Verification
- User Profile Management
- Meal Recommendation Engine
- Recipe Filtering
- Feedback System

---

## Project Structure

```bash
lowpoceat/
├── lowpoceat/      # Project settings
├── planner/        # Core application
├── templates/      # HTML templates
├── static/         # CSS / assets
├── manage.py
└── requirements.txt

```
---
Setup :
- git clone https://github.com/batcodez131003/lowpoceat.git
- cd lowpoceat
- pip install -r requirements.txt
- python manage.py migrate
- python manage.py runserver
